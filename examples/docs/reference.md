## Options

| Flag | Meaning |
|------|---------|
| `-T`, `--theme` | `dark` or `light` |
| `-w`, `--width` | Content width, `0` for auto |
| `-s`, `--slides` | Slide mode |
| `-l`, `--line-numbers` | Line numbers in code |
| `--export html` | Write HTML to stdout |
| `--no-color` | Plain text |
